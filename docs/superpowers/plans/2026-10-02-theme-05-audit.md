## Task 4: Fix loop (one task per approved finding, appended after approval)

Each fix is its own task and commit:

1. Write a failing test demonstrating the defect (unit if it can be a static or pure check, integration otherwise).
2. Run it and watch it fail for the right reason.
3. Make the smallest fix.
4. Run `composer lint`, `composer test:unit`, `composer test:integration` (both modes): all green.
5. Commit: `git add <code> <test> docs/superpowers/audit/2026-10-02-theme-audit.md` then `git commit -m "fix: <finding id> <summary>" -- <same paths>`, with the finding marked fixed in the same commit.

### Worked example (candidate 3, if confirmed): cast countdown IDs

- [x] **Step 1: Failing test** `tests/integration/FrontPageCountdownTest.php`

```php
<?php
namespace HyperPress\ThemeTests\Integration;

use WP_UnitTestCase;

final class FrontPageCountdownTest extends WP_UnitTestCase {

	public function test_only_integer_ids_reach_the_shortcode(): void {
		set_theme_mod( 'hyperpress_homepage_customize_countdowns', array( '12', '7" onload="x', 'abc' ) );

		$seen = array();
		add_filter(
			'do_shortcode_tag',
			static function ( $output, $tag, $attr ) use ( &$seen ) {
				if ( 'hyperpress_countdown' === $tag ) {
					$seen[] = $attr['id'] ?? null;
				}
				return $output;
			},
			10,
			3
		);

		$this->go_to( home_url( '/' ) );
		ob_start();
		include get_front_page_template();
		ob_end_clean();

		foreach ( $seen as $id ) {
			$this->assertMatchesRegularExpression( '/^\d+$/', (string) $id, 'countdown id must be an integer' );
		}
		$this->assertContains( '12', array_map( 'strval', $seen ) );
	}
}
```

If `front-page.php` only runs the loop when the site shows a static front page, set `show_on_front` to `page` and `page_on_front` to a created page first.

- [x] **Step 2:** Run, expect FAIL (the malformed value reaches the shortcode). **Step 3:** In `front-page.php`, build the shortcode from `(int) $countdown_id` and skip zero. **Step 4:** Run the test and the full suites: green. **Step 5:** Commit per the loop.
